# Waifu Companions

Полноценный NeoForge 1.21.1 мод с системой приручаемых вайфу-компаньонов.

## Возможности (реализовано в ядре)

- **Любой LivingEntity** может стать вайфу (ванильные и модовые мобы).
- Модель и внешний вид моба **сохраняются**.
- **Система характеров**: kind, shy, bold, cheerful, lazy, aggressive, caring, jealous, serious.
- **Отношения**: уровень отношений, affinity, trust, mood, satiety, energy, experience, level.
- **Память**: запоминает подарки и важные события (влияет на будущие диалоги).
- **Диалоги**: событийные, зависят от характера, уровня отношений, погоды, времени суток, настроения и т.д. Множество вариантов.
- **Стикеры/эмоции**: ❤️ 💕 😊 😳 😡 😢 😂 😴 💢 ❗ ❓ 💦 и др. (отображаются как action-bar + состояние).
- **Взаимодействие**:
  - ПКМ с золотым яблоком / золотой морковью / зачарованным золотым яблоком → попытка приручения.
  - ПКМ по прирученной вайфу (пустая рука) → погладить.
  - ПКМ с предметом → подарить/покормить.
  - Shift+ПКМ → поговорить (выбирает диалог по контексту).
- **Команды**: `/waifu status <entity>`, `/waifu tame <entity>` (op).
- **Данные**: полностью data-driven. Новые вайфу добавляются JSON-файлами в `data/waifucompanions/waifus/`.
- **Производительность**: логика только на событиях + редкие проверки (каждые 100 тиков). Нет тяжёлой логики каждый тик.

## Структура данных (waifus/*.json)

Смотри примеры `mio.json` и `yuki.json`.

Поля:
- `name`, `personality`
- `baseStats`
- `favoriteItems` / `dislikedItems` (полный ID предмета, например `minecraft:apple`)
- `dialogues` — объект событий → массив реплик (строка или `{text, minRel, maxRel, sticker}`)
- `stickers` — эмоция → список эмодзи
- `abilities` — список способностей (для расширения)

События диалогов: `first_meet`, `tamed`, `talk`, `pet`, `gift_liked`, `gift_disliked`, `return_long`, `low_mood`, `high_mood`, `night`, `rain`, `level_up` и любые кастомные.

## Этапы разработки (уже пройдены в коде)

1. Базовая система + Attachment
2. Приручение
3. Сохранение (Codec + copyOnDeath)
4. Система отношений
5. Характеры
6. Диалоги и события
7. Память
8. Стикеры (lightweight)
9. Базовые команды
10. Data-driven JSON
11. Оптимизация (event-driven)

## Как расширять

1. Добавь новый `.json` в `src/main/resources/data/waifucompanions/waifus/`.
2. (Опционально) Добавь логику способностей в событиях.
3. Для полноценного GUI и 3D-стикеров над головой — добавь client-side renderer и пакеты (заготовки network/gui уже есть).

## Сборка

```bash
./gradlew build
```

Готовый jar появится в `build/libs/`.

## Использование в игре

1. Найди любого моба.
2. ПКМ золотым яблоком (шанс ~40%) или зачарованным (100%).
3. Общайся, корми, гладь.
4. Следит за игроком (телепорт если далеко).

Мод совместим с любыми мобами, потому что работает через Attachment на LivingEntity.
